# Actividad 8 - Monitoreo y Gobernanza de Modelos de IA

Esta carpeta contiene la documentación correspondiente a la Actividad 8 de la materia Gestión de Proyectos de Inteligencia Artificial.

La documentación describe el diseño e implementación de una estrategia de monitoreo, observabilidad y gobernanza para un modelo de Machine Learning, incluyendo el seguimiento de métricas de desempeño, detección de incidentes, monitoreo de data drift, configuración de alertas y mecanismos de respuesta operativa.

Se incluyen un documento técnico con la propuesta de solución y un documento de evidencias que muestra la implementación y validación de los componentes desarrollados.
