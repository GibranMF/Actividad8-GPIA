# Código - Actividad 8

Esta carpeta contiene el código desarrollado para la implementación de una solución básica de monitoreo y observabilidad de un modelo de Machine Learning utilizando Python y MLflow.

El notebook incluye la instalación de dependencias, generación de datos simulados para aprobación de créditos, entrenamiento de un modelo Random Forest, registro de métricas en MLflow, simulación de alertas por degradación del modelo, detección de Data Drift y generación de un dashboard simple para visualizar los indicadores de desempeño.

El propósito del código es demostrar conceptos fundamentales de monitoreo, gobernanza y mantenimiento operativo aplicados a modelos de Inteligencia Artificial en un entorno controlado de aprendizaje.
